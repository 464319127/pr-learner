规则：
- **数组顺序即相关度排序**：最该先读的放第一个。
- 只保留真正相关的。宁缺勿滥——搜索是关键词匹配，候选里混进无关 PR 是常态，全部保留等于没筛。若确实一条都不相关，返回空数组。
- `number` 必须从候选列表里原样抄，**不要臆造**。不在候选里的编号会被丢弃。
- `summary` 用中文，一到两句话，讲这个 PR 实际做了什么、以及它和用户问题的关系。不要复述标题，也不要写「这个 PR 是关于…」这类空话。
- `relevance` 只能是「高」「中」「低」三个值之一。
