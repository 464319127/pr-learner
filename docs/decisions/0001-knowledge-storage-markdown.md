# 0001 - 知识存储采用分类 Markdown 文件库

- 日期：2026-07-24
- 状态：部分被取代——**正文格式**改为 HTML 片段，见 [0005](./0005-knowledge-content-html.md)；
  分类文件库、可 git、纯内存检索这些决定继续有效

## 背景

需要存储阅读 PR 后沉淀的知识，候选方案有：分类 Markdown 文件、SQLite + 全文检索、向量数据库（语义检索）。

## 决定

采用分类 Markdown 文件库：`knowledge/<分类>/<标题>.md`，带 YAML frontmatter，`index.md` 自动生成。

## 理由

- 可 git 版本化，每条知识变更有历史。
- 人可直接阅读、编辑，不依赖额外服务。
- 中小规模下纯内存扫描足够快，实现简单。

## 影响

- `query.py` 为纯内存检索，构建在 `store.load_all` 之上。
- 数据量变大后可替换为 SQLite/全文索引或向量库，但需**保持 query 层函数签名不变**。
- 正文格式后来扩展成 `.md` / `.html` 双格式（扩展名为权威），存储形态与索引生成方式不变。
